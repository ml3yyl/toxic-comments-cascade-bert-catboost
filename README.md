# Двухэтапный каскад моделей для многоклассовой модерации комментариев (L1 CatBoost + L2 RuBERT)

Интеллектуальная NLP-система модерации пользовательских комментариев на 4 независимых класса (`INSULT`, `NORMAL`, `OBSCENITY`, `THREAT`) в условиях экстремального дисбаланса данных (самый опасный класс угроз составляет всего 1.7%).

##  Исходные данные
В проекте используется открытый датасет:
[Toxic Russian Comments на Kaggle](https://www.kaggle.com/datasets/alexandersemiletov/toxic-russian-comments).

##  Архитектурное решение (Экономия GPU в 10 раз)
Использование тяжелых NLP-трансформеров в продакшене напрямую для миллионов запросов экономически нецелесообразно из-за высокой стоимости GPU-инфраструктуры и низкой скорости. 
В данном проекте реализована **каскадная схема инференса** :

1. **L1 Уровень (CatBoostClassifier):** градиентный бустинг, запущенный на ЦП, быстро обрабатывает **90.47%** всего входящего потока комментариев. Если бустинг полностью уверен в ответе (вероятности выходят за калиброванные рамки), он сам выносит вердикт, экономя 100% ресурсов видеокарты.
2. **L2 Уровень (RuBERT):** Если CatBoost сомневается и вероятности попадают в "серую зону" (20 % от оптимального порога), управление передается тяжелому трансформеру `DeepPavlov/rubert-base-cased-conversational` на GPU T4, который выносит экспертное решение на основе глубокого анализа контекста.

## Ключевые результаты и этапы проекта

* **Объем данных:** 248 290 реальных комментариев из социальных сетей.
* **Схема валидации:** Из-за мультилейбл-структуры и дисбаланса классов применена схема **`MultilabelStratifiedKFold`** на 5 фолдов, что гарантирует сохранение пропорций редких меток во всех выборках.
* **Калибровка порогов (Threshold Tuning):** Стандартный порог `0.5` неэффективен для редких классов. С помощью функционального поиска (`lambda`-оптимизация по пространству порогов с шагом `0.05`) были найдены индивидуальные точки отсечения (`INSULT`: 0.4, `NORMAL`: 0.5, `OBSCENITY`: 0.3, `THREAT`: 0.4), что подняло baseline-метрику **Macro F1-Score до 0.8034**.
* **Сборка "Серой зоны":** По калиброванным порогам была сформирована выборка сложных кейсов. Она составила всего **9.53%** (`23 670` строк) от исходного датасета.
* **Fine-Tuning RuBERT:** Нейросеть дообучалась на чистом PyTorch строго на данных серой зоны. Классификация строилась по скрытому состоянию **`CLS`-токена** (длина последовательности `max_length = 128`, `batch_size = 32`).
* **Борьба с дисбалансом в DL:** Для фокусировки внимания трансформера на дефицитных классах внедрена кастомная функция потерь **`MultiLabelFocalLoss`** с модулирующим множителем $(1 - p_t)^\gamma$. Это предотвратило застревание сети на легких примерах и подняло финальное качество системы на валидации до **Macro F1 = 0.8638** (+6.04% к результату бустинга).
